# 📚 Security Book Summaries (EN / AR)

Bilingual (English + Arabic) chapter-by-chapter summaries of offensive security / malware analysis books, written after reading each book cover to cover. Meant as study notes and a quick refresher — With the originals books .

## Index

| Book | Author(s) | Pages | Focus |
|---|---|---|---|
| [The Hacker's Codex](./hackers-codex/) | Brandon | 173 | Client-side web app attacks (CORS, XSS, CSRF, request smuggling, cache poisoning) |
| [Black Hat Bash](./black-hat-bash/) | Dolev Farhi & Nick Aleks | 347 | Offensive bash scripting across the full pentest lifecycle |
| [Black Hat Python](./black-hat-python/) | Justin Seitz | 193 | Writing custom hacking tools in Python (networking, web, trojans, forensics) |
| [Evasive Malware](./evasive-malware/) | Kyle Cucci | 490 | How malware evades sandboxes/debuggers/EDR — and how to counter it |
| [The Hacker Playbook 3](./hacker-playbook-3/) | Peter Kim | 264 | End-to-end red team operations (recon → AD compromise → reporting) |

Each folder holds that book's summary as its own `README.md` (so it renders automatically when you open the folder on GitHub). Feel free to drop your own legally-owned copy of the book's PDF into the matching folder before pushing — just don't commit copyrighted PDFs to a public repo.

## How these were made
Each summary was produced by reading the full PDF (table of contents, section structure, and representative content from each chapter), then distilled into a chapter-by-chapter table with a short takeaway, written in both English and Arabic.

## Disclaimer
These notes are for educational purposes. All original credit belongs to the respective authors — this repo exists to help readers (including myself) retain and reference the material faster, not to replace buying/reading the books.
